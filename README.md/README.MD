Vital pet es una tienda virtual enfocada en la venta de diversos productos para mascotas, va dirigida a dueños de gatos y perros que buscan productos alimenticios, accesorios, juguetes y productos saludables para el cuidado de tu mascota, la pagina permite la navegacion a travez de diversos productos, conocer sus beneficios, agragar los productos seleccionados al carrito de compras y realizar el proceso de pago por el medio elegido de manera sencilla.
Las principales funcionalidades que podemos encontrar en el proyecto esta el almacenamiento de productos en el carrito por medio del LocalStorage, el calculo automatico del subtotal, modificacion de las cantidades, eliminacion de productos del carrito y la validacion del formulario antes de fianlaizar el proceso de compra. Se implemento la verificacion de el metodo de pago, ocultando campos innecesarios para opciones como Nequi, Daviplata y Paypal y ademas la validacion de la fecha de vencimiento de la tarjeta e credito o debito segun corresponda.

Los principales requisitos para la ejecucion del sitio web son.
1. Navagador web actualizado (Google Chrome y Microsoft edge)
2.Conexion a internet para cargar fuentes e imagenes utilizadas en el desarrollo del proyecto
3.Para su ejecucion, no es necesario intalar o ya tener instalado software adicional.
4. JavaScript habailitado en el navegador para poder ejecutar el carrito de compras.

Para el desarrollo del proyecto se utilizaron las siguientes herramientas:
Visual Studio Code: Utilizado para la creacion y modificacion del codigo fuente.
HTML 5:Utilizado para la estructuracion del contenido del proyecto. 
CSS3: Diseño visual, estilos, animaciones y adaptacion a distintos dispositivos.
JavaScript:Implementado pára la logica de la pagina web, validaciones, funcionamiento del carrito y el almacenamiento de datos.
Github: Utilizado para alamcenar el repositorio y gestionar el proyecto.
Google Fonts: utilizado para integrar tipografías personalizadas para el proyecto.
CDN Fonts: utilizado para incorporar la fuente Bauhaus en la pagina web.
Imagenes de productos obtenidas en google en paginas de marcas y paginas de fotos para descargar 
Google chrome y Microsoft edge utilizados para verificacion de pruebas y validacion del funcionamineto de la pagina web
